Исследование туристических данных для выявления сезонных и географических закономерностей спроса 
2.2. Подобрать источники данных по требованиям п.3 и изучить их. 
Выбрать числовые и категориальные характеристики, представляющие аналитический портрет состояния объекта исследования и факторов влияния. 
3. Среди открытых источников данных по теме исследования найти: 3.1. не менее 1 реляционного набора данных; 
3.2. не менее 1 иерархического набора данных (формат XML); 
3.3. не менее 1 источника с API с выдачей в формате JSON; 
3.4. не менее 1 источника неструктурированных данных: в текстовом виде (статьи, посты, сообщения, сайты), аудио или видео. Допустимо получение по API.
Каждый использованный набор данных должен описывать множество объектов, относящихся к теме исследования, в не менее чем 3-х категориальных аспектах и не менее чем 3-мя числовыми характеристиками. 
Преимуществом будет наличие характеристики времени (дата и\или время). Весь список источников должен охватывать не только предмет исследования, но и данные описывающие возможные факторы влияния.
